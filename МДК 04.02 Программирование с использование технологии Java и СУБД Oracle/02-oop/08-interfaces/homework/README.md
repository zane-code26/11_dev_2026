# Домашнее задание: Пара 13. Интерфейсы

## Цель работы
Закрепить проектирование интерфейса и нескольких его реализаций на языке Java.

## Реализация
- Объявлен интерфейс `Exportable` с методом `String export()`.
- Класс `Invoice` реализует интерфейс `Exportable` и формирует строку с данными счёта (номер, клиент, сумма).
- Класс `ProductReport` реализует интерфейс `Exportable` и формирует строку с данными отчёта по продукции (категория, количество).
- В методе `main` создан массив интерфейсного типа `Exportable[]`, объекты обрабатываются в едином цикле через полиморфизм.

## Описание контракта интерфейса
Интерфейс `Exportable` определяет единый контракт экспорта: любой класс, реализующий данный интерфейс, гарантирует наличие открытого метода `export()`, возвращающего строковое представление объекта. Вызывающий код в `Main` работает с объектами исключительно через контракт `Exportable`, благодаря чему программа легко расширяется новыми типами без изменения логики вывода.

## Запуск программы
```bash
javac -encoding UTF-8 Main.java
java Main
```
