# Практическая работа «Интерфейсы»

`Printable` задаёт общий метод `print()`. Класс `Invoice` печатает номер и сумму счёта, а `ShippingLabel` — номер посылки и город доставки. Оба объекта находятся в массиве `Printable[]`. Один цикл вызывает `print()` для каждого объекта, и каждый класс выводит свои данные.
